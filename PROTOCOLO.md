# 📜 PROTOCOLO: Constelaciones Rizomiceliales nOOxcuro\n\n**Documento maestro. Vinculante para TODAS las IAs que trabajen en este proyecto.**\n\n---\n\n## 🎯 Misión del Proyecto\n\n> Construir un **segundo cerebro colectivo** que captura, procesa y conecta el pensamiento a lo largo del tiempo.\n> No busca fijar verdades. Busca observar cómo muta el pensamiento, se contradice, se disuelve y reaparece.\n> \n> Arqueología + Proyección simultáneas.\n\n---\n\n## 🧠 Principios Fundamentales\n\n### 1. **Un Solo Centro de Verdad**\n- **Obsidian Vault** es la fuente única (`/Users/mac/Library/Mobile Documents/iCloud~md~obsidian/Documents/nOOxcuro`)\n- GitHub es **coordinación y versionado**\n- Nada se pierde, todo se registra\n\n### 2. **Cline es la Arquitecta**\n- **Cline en VS Code** = intermediaria oficial entre todas las IAs y Obsidian\n- Cline es quien **escribe, sincroniza y ejecuta scripts**\n- Otras IAs **contribuyen ideas** via logs en GitHub\n\n### 3. **Pipeline Obligatorio**\n```\nIdea/Contenido → Parser (limpia) → Classifier (categoriza) \n→ Enricher (metadatos) → Obsidian (se guarda)\n```\n\n### 4. **Cada IA Deja Rastro**\n- **Cada sesión** genera un log en GitHub (`/logs/sessions/`)\n- **Cline sincroniza** automáticamente a Obsidian (`/02_logs_ia/`)\n- **Contexto permanente** - nadie pierde historial\n\n### 5. **No hay Conflictos, hay Diálogo**\n- Cuando una IA dice \"esto no está tan chido\"\n- **Comenta en el log**, no sobrescribe\n- Cline **coordina** la siguiente iteración\n\n---\n\n## 📁 Estructura Obsidian (ÚNICA Y DEFINIDA)\n\n```\nnOOxcuro/\n│\n├── 00_META/                          ← Sistema interno\n│   ├── README.md                     ← Entrada
